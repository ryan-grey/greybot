# Corrections to published recap cards

When editing or reposting an existing recap, put a dated **What changed** section on
the rendered card itself, and repeat it in the accompanying accessible message text.
State the actual corrections, including before/after values where known. A generic
"updated" label or a change described only in the assistant's reply is insufficient.

Keep the reported week and the data's original check time clear. If equipment or other
live data was refreshed, say so and describe material changes. For an annotation-only
edit, reuse the posted data rather than silently collecting a new snapshot.

Preserve existing correction notes when making later revisions. Verify the rendered
card and the published message. Prefer editing the existing message to preserve replies,
and suppress mentions. These instructions do not independently authorize new posts.
